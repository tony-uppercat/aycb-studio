# AYCB v2 — Session Report 2026-05-10

## What We Did
Two things. One: shipped a fix to the OpenAI image generator. The
`4K` resolution selection on `gpt-image-2` was silently producing
~1 MP images while still billing the high-quality price. Now `4K`
actually generates ~8 MP at 3840 max edge. Also added an `FHD` preset
(OpenAI only) for ~1920×1088 output — useful when you want video-spec
sizes without paying for full 2K. Two: brainstormed and documented
a new "per-ID JSON mode" for the Generate Image node — not yet
implemented, but the design and plan are committed and ready to
execute.

## What Changed (shipped)
- `4K` no longer cheats: it generates real 4K instead of secretly
  rendering at 1K.
- New `FHD` option in the resolution dropdown — visible only when an
  OpenAI model is selected. Maps to 1920×1088 at 16:9 (8-pixel
  difference from true 1080 because OpenAI's API requires multiples
  of 16). 9:16 mirrors to 1088×1920.
- Cost estimate updated: 4K now shows $0.50 (was $0.211, which was
  wrong — both because of the silent downgrade and because the real
  4K cost is roughly 4× the 2K cost).
- 1K behavior across aspect ratios was reviewed; confirmed the
  current ~1.05 MP target is what you want. No code change.

## Design Done (not yet built)

  next to `EDIT`/`GND`; if `prompt-in` carries a JSON array of
  strings (`["prompt 1", "prompt 2", ...]`), Run generates one
  image per entry and exposes them on dynamic `image-0`, `image-1`,
  ... output pins (plus `image-out` for the last successful one).
  Parallel batches of max 4. Mutually exclusive with EDIT.
