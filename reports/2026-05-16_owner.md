## Addendum — CLI Batch Generation (Thread 3, sera 2026-05-15 → 2026-05-16)

### What We Did
1. Aggiunto un workflow CLI per la batch generation: due script in
   `scripts/` (uno sync Flash 1K, uno async Pro 2K via Gemini Batch API
   al 50% di sconto).
2. Generata la prima batch reale: 3 reference sheet 16:9 per i pennelli
   PAO partendo da foto prodotto (cartella esterna Dropbox).
3. Codificato tutti i pattern emersi (downscale ref, retry, log, cost
   table, crash-recovery batch) in una nuova skill di progetto
   `aycb-cli-generation` che si attiva automaticamente quando si
   tocca `scripts/`.

### What Changed
- Nuovo script `scripts/batch_brush_refsheet.py` — Flash 1K sync, con
  log file `batch_YYYYMMDD_HHMMSS.log`, tabella costi USD per file,
  skip-if-exists, retry su 5xx, pre-downscale automatico delle ref
  pesanti.
- Nuovo script `scripts/batch_brush_refsheet_async.py` — Pro 2K via
  Batch API ufficiale, prezzo dimezzato, polling 10s, persistenza
  `job.name` su disco per resume dopo crash. Pronto ma non ancora
  lanciato (in attesa di tuo OK).
- Nuova skill di progetto `skills/aycb-cli-generation/SKILL.md` con
  tutti i pattern (boilerplate, gotchas modello, batch API JSONL).
- CLAUDE.md aggiornato: trigger esplicito per caricare la skill
  ogni volta che si lavora in `scripts/`.

### Empirical findings (utili per il futuro)
- Pro Image 2K va in HTTP 503 "Deadline expired" con ref >40 MB / 8K
  pixel. Pre-downscale a 1536px JPEG q=92 risolve completamente —
  3/3 verde su Flash 1K dopo downscale.
- Flash 1K con ref ottimizzate: 14-31s per immagine, ~$0.083 cad.
- Pro 2K via Batch async stimato ~$0.15/immagine (50% sconto).
