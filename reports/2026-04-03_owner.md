# AYCB v2 — Session Report 2026-04-03 (Session 3)

## What We Did
Fixed the shared directory misalignment between AYCB and Review Hub, rebuilt the hard restart mechanism to stop spawning CMD windows, and centralized all path configuration into a single setting.

- Shared path is now a single `shared_root` setting pointing to `Documents/shared/` (outside repo), with derived properties for Media, References, thumbnails, and DB
- Hard restart uses uvicorn's native file watcher instead of spawning new processes — touch a .py file, reloader respawns the worker
- New "Paths" tab in Settings panel to view/edit shared root and open in Explorer
- Desktop launcher updated with `--reload` flag
- CLAUDE.md updated with restart checklist and shared root documentation
