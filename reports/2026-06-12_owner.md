# AYCB v2 — Session Report 2026-06-12

## What We Did

Added a "Claude via local CLI" option to the LLM node. You can now pick
Opus 4.8 / Opus 4.6 / Sonnet 4.6 "(Local CLI)" and run them through your
logged-in `claude` subscription — no API key, no metered API cost. Text and
image inputs both work. Then debugged and fixed two real-world failures you
hit while testing it.

## What Changed

- **New:** three "(Local CLI)" Claude models in the LLM node dropdown. They
  shell out to the local `claude` command instead of the paid Anthropic API.
- **Fix 1:** generic "claude exited 1" errors. The model was wandering into
  tool use and running out of turns. The node is now locked to pure text
  generation (no tools; only image reading when images are attached), and real
  error reasons are surfaced instead of a useless code.
- **Fix 2:** "The command line is too long" with a big system prompt. The
  system prompt is now handed off via a file, so size no longer matters.

## Current State

subscription-equivalent reported by the CLI (includes its system-prompt
overhead, ~$0.09–0.22 for tiny prompts). 318 backend tests + 431 frontend
tests green.
