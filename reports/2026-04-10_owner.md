# AYCB v2 — Session Report 2026-04-10

## What We Did
Rebuilt the Generate Video node from scratch with three providers (fal.ai, Atlas Cloud, PiAPI), a cleaner UI with provider filter buttons, proper cost tracking, and automatic saving of generated videos to the Media folder so they appear in Review Hub.

## What Changed

### Video generation
- **3 providers available**: Atlas Cloud (default, most reliable), fal.ai (Kling with audio), PiAPI (cheapest Seedance Fast)
- **8 models in total** with clear pricing from $0.07/s to $0.30/s
- **Provider filter** — click fal.ai / Atlas / PiAPI to filter the model list
- **Default setup**: Atlas Cloud → Seedance 2.0 → 21:9 ratio

### Multi-reference support
- Connect multiple images to the video node (up to 12)
- Connect a video or audio URL as reference
- All three providers handle refs differently — we auto-pick the right mode

### Cost tracking
- **Before running**: shows estimated cost based on model × duration
- **After running**: shows actual cost in the node footer
- **Console panel**: all video costs tracked alongside image costs

### Media gallery integration
- Videos are now **downloaded and saved** to `shared/Media/` automatically after generation
- Videos appear in **Review Hub** (scanner picks them up)
- **Metadata saved**: prompt, model, cost, duration, aspect ratio in sidecar JSON
- **History** in the node: navigate through previous videos with arrow buttons

## Current State
- Atlas Cloud Seedance 2.0 Fast tested and working (3 videos generated successfully)
- PiAPI Kling and Seedance tested — tasks reach the API, multi-ref now uses `omni_reference` mode
- fal.ai ready for testing (Kling 3.0 Omni)
- All 307 tests passing
- Videos visible in Media Gallery and Review Hub
